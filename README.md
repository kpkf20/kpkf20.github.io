# 대한민국 직업강사 파크골프연맹 홈페이지

공개 주소: https://kpkf20.github.io/

## 페이지

| 파일 | 내용 |
|---|---|
| index.html | 홈 (첫 화면, 대회 공지, 자격과정 요약, 최근 소식) |
| about.html | 협회소개 (인사말, 설립목적·비전, 연혁, 오시는 길) |
| courses.html | 자격과정 (과정 안내, 신청·취소, 자격증 조회) |
| branches.html | 전국지사현황 (지사 목록 + 지도) |
| press.html | 보도자료 |
| share.html | 공유 (공지사항, 자료실, 갤러리, 오픈채팅방) |
| privacy.html | 개인정보처리방침 · 이메일무단수집거부 |

## 공통 파일

| 파일 | 내용 |
|---|---|
| site.css | 모든 페이지의 디자인 |
| site.js | 신청서, 지도, 목록 등 동작 |
| data.js | **보도자료, 지사 정보, 신청 이메일** ― 자주 바뀌는 내용은 이 파일만 고치면 됩니다 |
